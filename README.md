# Curb Appeal

A leaf blowing game. Get 90% of the leaves onto the blue tarp, fast, without draining the tank.

The whole game is one static file, `index.html`. There is no build step. Open it in a browser to play locally.

## Controls

- Desktop: point with the mouse and he follows. Hold click (or space) to blow. WASD overrides the follow. R restarts.
- Phone: left thumb walks, right thumb aims and blows.
